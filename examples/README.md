# Examples

Real output from the skills, unedited.

## shipnote

`shipnote` is a fictional CLI. Its [README](shipnote/README.md) was the only input. In a project holding just that file, with `edt-core` and `edt-synthesize` installed, this command produced both pages:

```
/edt-synthesize:empathy-map release engineer using shipnote
```

- [`design-thinking/empathy-map-release-engineer.html`](shipnote/design-thinking/empathy-map-release-engineer.html): the empathy map ([view it live](https://barvhaim.github.io/ibm-design-thinking-marketplace/examples/shipnote/empathy-map-release-engineer.html))
- [`design-thinking/simulated-users.html`](shipnote/design-thinking/simulated-users.html): the simulated users panel the map drew on ([view it live](https://barvhaim.github.io/ibm-design-thinking-marketplace/examples/shipnote/simulated-users.html))

The pages are artifact bodies: they start with `<title>` and have no `<!doctype>`, because the Artifact host adds the document skeleton. The docs site adds the same skeleton when it serves them.
